# ADR-0003: Event-driven monitoring

Status: accepted

## Context
Idle CPU and wakeups are hard budgets.

## Alternatives
Rapid polling; notifications only.

## Decision
IOPS notification source, workspace sleep/wake and clock events, one 60-second fallback timer with tolerance. Sample history at most every five minutes using that event path.

## Consequences and trade-offs
No wake alarms; recompute current schedule after wake. Flush history in bounded batches.
