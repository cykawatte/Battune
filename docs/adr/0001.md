# ADR-0001: Hybrid Swift and Rust

Status: accepted

## Context
Keep policy deterministic and independent of platform frameworks.

## Alternatives
Swift-only; C++; Rust UI.

## Decision
Swift owns lifecycle and system integration; dependency-free Rust owns policy. A fixed-width value ABI carries complete input and output.

## Consequences and trade-offs
Two toolchains; ABI tests required. No cross-language heap ownership.
