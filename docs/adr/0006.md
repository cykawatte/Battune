# ADR-0006: Minimum supported macOS

Status: accepted

## Context
Modern helper registration and native charts require a baseline.

## Alternatives
Older macOS with SMJobBless; newest OS only.

## Decision
macOS 13 minimum; SwiftPM builds with installed stable Swift. arm64 primary; optional x86_64 and universal artifacts.

## Consequences and trade-offs
Older systems unsupported; actual cross-version and Intel runtime testing remains required.
