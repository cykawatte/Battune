# ADR-0005: Persistence and history

Status: accepted

## Context
Configuration is small; history must be bounded and private.

## Alternatives
SQLite; Core Data; unbounded logs.

## Decision
Validated versioned Codable settings in UserDefaults. Bounded atomic JSON history in Application Support. No periodic writes if samples are unchanged. Calibration journal records interruption; restart requires explicit recovery.

## Consequences and trade-offs
No runtime dependencies. Invalid settings are rejected and control disabled, rather than silently enabling defaults.
