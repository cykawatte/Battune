# ADR-0004: Capability-driven hardware backends

Status: accepted

## Context
Undocumented SMC writes can damage system behavior.

## Alternatives
Model whitelist; historical key guesses.

## Decision
Separate Apple Silicon and Intel backends with live read capability detection. Writes return unsupported until key semantics, readback and reset are physically validated. Test mocks never ship in Release.

## Consequences and trade-offs
Charge policy is testable end to end but production charge manipulation is unavailable initially; UI must say so.
