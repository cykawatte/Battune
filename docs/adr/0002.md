# ADR-0002: Privilege separation and XPC

Status: accepted

## Context
Hardware mutation may require root. Local callers are untrusted.

## Alternatives
In-process root; shell commands; legacy SMJobBless.

## Decision
SMAppService LaunchDaemon and narrow NSXPC protocol. Authenticate a signed client using its audit token and the same Team ID as the helper. Unsigned helpers reject connections.

## Consequences and trade-offs
Development monitoring works without helper privileges. Signed integration needs credentials and explicit registration.
